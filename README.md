# TCP Connecting
Данный проект представляет собой модуль (шаблон) для реализации
TCP-соединения между сервером и клиентом.
Модуль предоставляет шаблонную реализацию сетевого взаимодействия,
которую можно легко интегрировать в любой Java-проект.
## Требования для соединения
Для установки соединения необходимо:
<ul>
<li>Сервер и клиент должны находиться в одной сети (локальной или интернет)</li>
<li>Клиент должен знать IP-адрес сервера</li>
<li>Оба приложения должны использовать одинаковый порт (по умолчанию 8080)</li>
</ul>

## Особенности модуля
<ul>
<li>Готовые классы для сервера и клиента</li>
<li>Прозрачная обработка сетевых соединений</li>
<li>Callback-интерфейсы для обработки событий</li>
<li>Поддержка многопользовательского режима (для сервера)</li>
<li>UTF-8 кодировка сообщений</li>
<li>Обработка сетевых ошибок</li> 
</ul>

## Подключение модуля к проекту
### Callback-методы
Для подключения надо написать следующие callback методы,
реализовав интерфейс EventClientListener/EventServerListener 
соответсвенно:
<ul>
<li>onConnectionReady - при подключении</li>
<li>onReceiveString - при получении сообщения</li>
<li>onDisconnect - при отключении</li>
<li>onException - при исключении</li>
</ul>
Дополнительно для EventServerListener надо реализовать
метод setIP который возвращает IP-адрес, необходимый для
подключения Клиента к Серверу.

### Дополнительные возможности
Рассылка сообщений всем клиентам (сервер):
```
server.sendToAllConnection("Hello all clients!");
```
Отправка сообщения (клиент):
```
client.sendMessage("Hello server!");
```
